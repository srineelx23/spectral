# Angular v14 Rules (Legacy Decorator-Based)

## Component Architecture
- **NgModules**: Use `NgModules` for component organization. Ensure every component is declared in a module.
- **Decorators**: Use `@Component`, `@Directive`, and `@Pipe` as primary structural elements.
- **Standalone**: Do NOT use standalone components unless the project specifically targets them (Standalone was introduced in v14 but was not the standard).

## State Management
- **No Signals**: You MUST NOT use Signals.
- **Reactive State**: Use `BehaviorSubject` or `Subject` from RxJS for state management.
- **Plain Properties**: Use plain class properties with `ChangeDetectorRef` if necessary, though `OnPush` with Observables is preferred.

## Dependency Injection
- **Constructor Injection**: Use the class constructor for dependency injection. Do NOT use the `inject()` function.
- **Root Services**: Use `providedIn: 'root'`.

## Templates & Control Flow
- **Structural Directives**: You MUST use `*ngIf`, `*ngFor`, and `[ngSwitch]`.
- **Async Pipe**: Use the `async` pipe to subscribe to Observables in templates.

## Inputs & Outputs
- **Decorators**: Use `@Input()` and `@Output()` decorators exclusively.

## Performance & Memory
- ***ngFor TrackBy**: You MUST implement and use a `trackBy` function for all `*ngFor` loops to prevent unnecessary DOM re-renders.
- **Unsubscribing**: You MUST manually unsubscribe from all Observables in the `ngOnDestroy` lifecycle hook using the `takeUntil` pattern with a `Subject` to prevent memory leaks.
