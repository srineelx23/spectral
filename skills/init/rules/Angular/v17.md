# Angular v17 Rules (Modern Transition)

## Component Architecture
- **Standalone Components**: Always use standalone components. You MUST explicitly set `standalone: true` in the `@Component` decorator.
- **Change Detection**: Set `changeDetection: ChangeDetectionStrategy.OnPush`.
- **Host Bindings**: Prefer the `host` property in the `@Component` decorator over `@HostBinding`/`@HostListener`.

## Signals & State
- **Signal State**: Use `signal()` and `computed()` for component state.
- **Inputs/Outputs**: Use the standard `@Input()` and `@Output()` decorators. (Note: functional `input()` is in developer preview; avoid unless requested).
- **Update Logic**: Do NOT use `mutate`; use `set` or `update`.

## Dependency Injection
- **Inject Function**: Use the `inject()` function for DI.
- **Root Services**: Use `providedIn: 'root'`.

## Templates & Control Flow
- **Native Control Flow**: Use `@if`, `@for`, and `@switch`.
- **Async Pipe**: Use the `async` pipe for handling Observables.
- **Logic**: Keep logic out of templates.

## Performance & Interop
- **@for Tracking**: You MUST include the `track` expression when using `@for` to prevent performance issues (e.g., `@for (item of items; track item.id)`).
- **RxJS Interop**: Use `toSignal()` to convert Observables to Signals, and `toObservable()` to convert Signals to Observables when interfacing with RxJS code.
- **DestroyRef**: Use `inject(DestroyRef)` and `takeUntilDestroyed()` to manage RxJS subscriptions without implementing `ngOnDestroy`.
